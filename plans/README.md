## Recommended execution order

1. **001** — highest leverage; ships accessibility to the embed that runs on
   customers' sites. Introduces `src/lib/use-prefers-reduced-motion.ts`, reused
   by 002 and 003.
2. **002** — completes WCAG 2.2.2 for the marquee (pause reachable by all input
   methods).
3. **003** — independent polish; can be done anytime after the hook from 001
   exists.

## Dependencies

- **002 depends on 001**: it uses the `animate` flag 001 adds to
  `testimonial-masonry-animated.tsx` (hides the pause button under reduced
  motion). Both edit the **same file** — apply 001, then 002, sequentially (do
  not run them in parallel worktrees).
- **003 depends on 001 only for the hook file** (`use-prefers-reduced-motion.ts`).
  It edits different files (`globals.css`, the inbox page), so it can run in
  parallel with 002 once 001 has landed. If you run 003 first, create the hook
  file from 001's Target section as its step 0.
