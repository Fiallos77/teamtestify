Cómo usar esta página:
  1. Copia el snippet del widget desde el editor en el dashboard (los dos tags de abajo).
  2. Reemplaza el bloque marcado "PEGA AQUÍ" más abajo en este archivo con ese snippet.
  3. Guarda el archivo y recarga esta página en el navegador.

Importante: pega el snippet una sola vez. Si dejas más de un <div data-testimonial-widget> en la página, cada uno monta su propio widget — por eso se veía duplicado.
